# practice-game

异星坠毁题材的轻度游戏脑暴项目：**简化工厂（无物流）+ 塔防守家 + 线索叙事 + 多结局**。  
面向轻度玩家 / 摸鱼向；技术意向为 TypeScript + Canvas 自研（未开工定稿）。
