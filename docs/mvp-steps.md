## 表现口径（先读）

本游戏是 **Isometric 2D（等距 2D / 常称 2.5D 等距）**：

- **2D 图片与序列帧动画**（精灵），画成斜俯视的「伪 3D」感  
- **固定镜头、不可旋转**  
- **菱形格 / 等距坐标** + **深度排序**（谁挡谁）  
- **不是** Three.js / 真 3D 场景；**也不是**纯正顶视（orthographic top-down）为最终目标  

实现上可用极简色块代替美术，但**坐标与绘制管线按等距 2D 来**。若某步暂时用正交格子验证逻辑，须在该步注明，并尽快回到等距。
