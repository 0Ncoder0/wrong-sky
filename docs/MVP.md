## 1. 目标

### 1.1 玩法一句话

在 **32×32、整图可见** 的小地图上：点矿自动采、手搓建筑与多数材料、**组装机**产火箭零件、建造**发射台**并在其上再合成一次（建筑变外观动画）→ 发射与升天结束动画通关。  
**当前总耗电**越过三个阈值后，从**固定刷怪点**刷出**同一种敌人**（三波数量不同）；怪只攻击最近建筑；用耗弹药的炮塔防守。失败条件仅为**玩家死亡**。

### 1.2 能力验证一句话

顺带验证：场景流、输入、格子建造、动画、音效、UI、科技、存档、可构建运行，而不只是「会动的玩法 demo」。

## 2. 必须实现（玩法）

| 块 | 规格 |
|----|------|
| 表现 | **Isometric 2D（等距 2D）**：固定镜头不可转；**2D 精灵 / 序列帧**做出斜俯视感。非真 3D，亦非以正俯视为最终目标。详见 [`mvp-steps.md`](./mvp-steps.md) |
| 地图 | 约 **32×32** 方形；**整图可见**；无小地图、无迷雾 |
| 控制 | **WASD** 与 **鼠标右键** 移动；点矿点后人物**自动采集**；只移动 + **自动攻击**；**可暂停** |
| 库存 | **仅口袋**（全局数字库存）；无仓库建筑、无占格上限、无仓库被毁/拆仓逻辑 |
| 资源 | 至少包含**石头**（建筑需要）；以及矿与加工链中间物、弹药、火箭零件等（具体表实现时定，保持短） |
| 电力 | **仅太阳能板**；关闭的机器不耗电；炮塔**固定耗电**（交战与否相同） |
| 建筑类型 | **采矿类**、**生产类**；另含炮塔、组装机、发射台；建筑均可**手搓建造**（放置） |
| 建造放置 | 支持幽灵预览与可放/不可放；**不支持旋转** |
| 生产 | 除**火箭零件必须组装机**外，其余材料允许手搓 |
| 发射台 | **需建造**的建筑；零件齐后在台上**再合成一次**；合成**不耗电**；合成后**建筑外观变化动画** |
| 终局 | 火箭**发射建筑动画** → **升天后结束动画** → 结局；回标题可再开 |
| 刷怪 | 看**当前总耗电**；**三个阈值** → 最多三波；**一种敌人**；每波数量不同；**一个固定刷怪点** |
| 敌人 AI | **直奔最近建筑**；不主动追人 |
| 炮塔 | 需要**弹药** |
| 墙 | **不做** |
| 科技 | **可见科技树**；研究需**耗时**；**一次只能研究一个**；**不做**研究队列 |
| 失败 | **仅玩家死亡**（缓慢回血）；建筑可被毁后重建，发射台被毁不单独算通关失败 |
| 音频 | 需要**音效**（采、造、攻击、受击、解锁、发射、UI 等，具体列表实现时定） |
| 动画 | 角色与敌人的**移动 / 攻击**（2D 图/帧）；发射台变形；火箭发射；升天结束 |

发电与火电：**不要火电**（及煤电等），仅太阳能。

## 3. 必须实现（工程 / 能力验证）

| 优先级 | 项 | 说明 |
|--------|----|------|
| P0 | 场景流 | 标题 → 游戏中 → 暂停 → 死亡 → 结局 → 回标题 |
| P0 | 建造放置 | 幽灵预览、合法格校验（无旋转） |
| P0 | 音效总线 | 多事件 SFX + 总音量/开关 |
| P0 | 动画状态 | 人/怪 idle·walk·attack；建筑变形与发射 |
| P0 | UI | 口袋库存、建造列表、可见科技树（含进行中倒计时） |
| P1 | 存档 | **localStorage**，**JSON**；至少手动或自动存读一档 |
| P1 | 资源约定 | 统一格尺寸/锚点；可用占位图，逻辑与换皮分离 |
| P1 | 可交付构建 | 例如 `npm run build` 产出可打开游玩的静态页 |

技术栈意向（与 IDEAS 一致，本版落实）：**TypeScript + Canvas**，自研小框架即可。  
实现顺序与能力点拆分见 [`mvp-steps.md`](./mvp-steps.md)（仅指导 `mvp` 分支）。

## 4. 明确不做（本版）

- 仓库、物资分物品容量上限、拆仓/炸仓掉落等仓储复杂逻辑  
- 建筑表开关控产  
- 火电 / 煤电 / 核电 / 储能策略 UI  
- 迷雾、一次性开图建筑、卫星/飞船中台、小地图  
- 墙、建筑旋转  
- 多敌人种类、随机多刷怪点、追人 AI、绕墙等高级寻路（最近建筑直奔即可）  
- 多结局、导航/休眠检定、虫洞/线索/治星/殖民/反物质冲击/迷你黑洞等  
- 科技树「未知感 / 只显示当前一个」方案（已改回可见树）  
- 研究队列、并行研究  

完整愿景仍见 [`IDEAS.md`](./IDEAS.md)；本文件优先于 IDEAS 中与 MVP 冲突的表述。

## 5. 完成定义（DoD）

同时满足视为 MVP 过关：

1. 能走通：打开 → 玩到发射 → 看完结束动画 → 回标题再开一局  
2. 过程中用过：采矿建筑、生产建筑、太阳能、炮塔（耗弹）、组装机、发射台；完成至少一次耗时科技研究；触发过至少一波按耗电阈值的刷怪并用炮塔防守  
3. 具备：暂停、死亡界面、约定动画与音效、可见科技树（单研究）、localStorage JSON 存读、可 build 出的可玩包  

---

## 6. 实现时再定（不阻塞开工）

- 具体物品 / 建筑 / 科技节点名称与数量（保持短链）  
- 三档耗电阈值数值与每波敌人数量  
- 弹药消耗速率、太阳能发电量、各建筑耗电表  
- 存档键名、自动存还是手动存  
- 占位美术风格与音效素材来源
